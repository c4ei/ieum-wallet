# IEUM Wallet v1.0.2.0 — 콜드월렛 QR 연결

- 입력한 받는 주소와 금액을 기준으로 nonce·Chain ID·gas 정보를 자동 구성합니다.
- 미서명 거래를 USB JSON뿐 아니라 QR 및 PNG 이미지로 제공합니다.
- 콜드월렛의 서명 QR 이미지를 읽어 원래 거래의 보내는 주소, 받는 주소, 금액, nonce, gas와 대조합니다.
- 모든 항목이 일치한 경우에만 `eth_sendRawTransaction` 전송 버튼을 활성화합니다.
- QR 자동 인식 미지원 환경에서는 기존 문자열 붙여넣기와 USB 방식이 유지됩니다.

표시 버전은 `1.0.2.0`, 내부 SemVer는 `1.0.2-0`입니다.
